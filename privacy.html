Privacy Policy

Last updated: November 18, 2026

1. Who uses the app

Clipador App is a personal desktop application used by a single creator on their own accounts. It has no public users and no server of its own that collects data from third parties.

2. Data accessed

  • TikTok (Login Kit, user.info.basic): basic profile information (open ID, display name, avatar) of the creator's own account, used only to confirm which account authorized the app.
  • TikTok (Content Posting API, video.upload): used to send the creator's own video clips to their TikTok account as drafts.
  • YouTube (Data API): used to upload the creator's own videos and read basic statistics (views, likes) of those videos.

3. Storage

Access tokens are stored only on the creator's own computer, in local files that are not shared or published. The app does not sell, share or transfer this data to anyone, and does not use it for advertising.

4. Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Revoking access

Access can be revoked at any time in the TikTok app (Settings and privacy, Security and permissions, Apps and services) and in the Google Account permissions page. Deleting the local token files also removes the app's access.
